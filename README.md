# Emulation-based Neuromorphic Control for the Stabilization of LTI Systems

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

## Overview

This repository provides the **MATLAB code** for all simulations in the paper "Emulation-based Neuromorphic Control for the Stabilization of LTI Systems."
It includes the code to generate the figures and data of the simulation examples in the paper, [which can be found on arXiv](https://arxiv.org/abs/2511.11875).
